Nova

Nova is a simple programming language written in Python, designed to make programming easier to learn and read.

Nova uses Turkish syntax for its core commands and is being developed as an independent programming language.

🚀 Current Features

- "yaz()" — print text or variables
- "soru()" — get user input
- Variables
- Basic arithmetic
  - "+" addition
  - "-" subtraction
  - "x" multiplication
  - "/" division
- "eğer" — conditional statements
- Comparisons
  - ">"
  - "<"
  - "="
- "sil()" — clear the screen and variables

💻 Example

isim = soru("Adın ne? ")
yaz(isim)

sayi = 10

eğer sayi > 5:
    yaz("Sayı 5'ten büyük!")

🎯 Goal

The goal of Nova is to create a programming language that is easy to understand while having the potential to grow into a more powerful general-purpose language.

Nova is still in early development, so the language and its syntax may change over time.

📦 Version

Current version: 0.5

Nova 0.5 is an early release focused on the core language features.

🛠️ Development

Nova is currently being developed in Python.

The interpreter is being built from scratch as part of the project.
